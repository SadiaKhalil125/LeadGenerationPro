# NEW UNIFIED COMMAND: Supports both localhost (for local services) and host.docker.internal (for K8s/Docker)
# This uses two listeners on different ports:
# - Port 9092: advertised as localhost:9092 (for scheduler and status_updater running locally)
# - Port 9093: advertised as host.docker.internal:9093 (for worker and status_updater in K8s)
# Exposes both ports so both local and Docker services can connect
